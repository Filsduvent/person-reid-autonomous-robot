# Technical review of bounded recovery evidence

This review is restricted to the approved Phase21 matrix. It is an implementation/evidence review, not scientific acceptance of eventual retrieval results, demonstrated convergence, matched compute, or a full-epoch CUDA bitwise guarantee. Final case status and references are recorded in `qualification_results.yaml`; this document alone grants no qualification.

The corrected GPU harness preserves the actual common observed source loader and public global PK sampler. It bounds the observer iterator to one batch, keeping the source population, canonical maps, actual combined source C, P16/K4/B64, pixels/augmentation, pinned ImageNet initialization, MGN/loss/SGD recipe and strict numerical execution controls. The production validator rejects fixture budgets and output namespaces. Test-local patches never become official configuration options.

For each fold, the first recovery child executes two calls and publishes the normal two-generation completed-boundary state. A new process explicitly restores the retained boundary after update1, performs update2 once and stops before a further batch/update. The resulting model (including BN buffers), SGD momentum, scheduler, RNG/PK state, checkpoint source identity/position, consumed indices, LR trace and source exposure are compared exactly with the uninterrupted update2 state. The shared checkpoint reader, CPU-before-CUDA integrity gate, state placement, restore and common training orchestration are exercised. Timings and recovery journal events differ legitimately and are not equality claims. The immutable per-case ledger accounts for all3 physical optimizer entries across both children. Intentional replay of an older retained branch is fixture work; a conservative unknown-discarded-work flag in the ordinary journal is not converted to an invented physical zero.

The complementary CPU/index experiment exhausts two actual metadata-only source epochs per fold, restores the RNG state at the first completed epoch boundary and reproduces the entire next epoch's original PK indices. This proves serialization/restoration of those real sampler states without reading source pixels, optimizing models or initializing CUDA. The CPU checkpoint/corruption/fallback/terminal tests exercise invalid retained generations, scheduler/counter consistency, exact budget/terminal no-op and longer orchestration; their actual commands/results are retained separately.

The inference is limited: the production recovery state contains completed epoch position, model/BN, optimizer/scheduler, RNG and sampler states rather than an arbitrary in-flight cursor. The fixture and real-index tests exercise those mechanisms from complementary directions. They do not execute a full source-image CUDA epoch, verify all future kernels or interactions, simulate every abrupt I/O/process/power failure, or prove long-run hardware reproducibility. Official runs must preserve runtime/UUID/source/config/data bindings and report unknown unobserved physical work. Any stronger empirical guarantee requires a separately approved scope.

Convolution TF32 permission remains true, matmul TF32 false, tensor dtype float32 and AMP disabled. RTX A4000 capability8.6 supports TF32; no measured-kernel claim or full-FP32 arithmetic guarantee is inferred. The observed GPU evidence includes the actual permission/capability/runtime and memory footprint.

Only a fold whose forward and recovery cases both pass, whose real-index/CPU checks pass, and whose source/data/runtime evidence matches the current reviewed release may receive the bounded qualification record. The corresponding private record cites this review and preserved evidence hashes. The user remains the operator who initiates official training. Single-seed and CUHK03 provenance limitations remain unchanged; target evaluation is not part of qualification or the training launch authority.
